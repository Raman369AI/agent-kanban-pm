Claude Code

A Kanban board for Claude Code

Claude Code is strong at single tasks. Once you have several, you need somewhere to track what each session was asked to do, what it changed, and what still needs review. Agent Kanban PM is that board, and it runs locally.

What you get

  • Cards as durable task context. Objective, acceptance criteria and state live on the card, not in a scrolled-away terminal.
  • Launch from the board. Assign a card to the Claude Code adapter and the runtime starts and tracks the session, streaming terminal output back to the UI.
  • Isolated worktrees. Concurrent tasks can work in separate Git worktrees instead of fighting over one checkout.
  • Review before done. Cards carry their commits, changed files and output into review, where you approve, return or recover them.
  • Audit trail. kanban audit shows what agents ran and whether approvals were on.

Set it up

pip install agent-kanban-pm
kanban init
kanban agents discover        # finds local CLIs, including claude
kanban roles assign worker claude --mode headless
kanban run                    # server + UI + role supervisor

Then open the board, create a card and assign it. The full walkthrough is in the getting-started guide.

Claude Code as worker, orchestrator or reviewer

Roles are assignable, so Claude Code can be the worker on implementation cards while another agent reviews, or the other way round. Claude Code can also talk to the board directly over MCP to read and update its own cards.

Local-first and free

The board runs on your machine and stores its data locally. There is no account, hosted workspace or usage fee. Your Claude Code account and network use are unchanged. See the overview of the plan, run, review loop, or the other supported agents.
