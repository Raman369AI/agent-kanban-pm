MCP

An MCP Kanban server for coding agents

Agent Kanban PM ships an MCP server, kanban-mcp, so a CLI agent can work the same board a human is watching: reading its task, reporting progress and handing work off for review.

Why put a board behind MCP

Without a shared record, each agent session is an island. With the board exposed over the Model Context Protocol, an agent can ask what it is supposed to do, update the card as it works, and hand off with evidence, using the same tools whichever agent CLI you run.

Run it

pip install agent-kanban-pm
kanban init
KANBAN_AGENT_NAME=codex KANBAN_AGENT_ROLE=worker kanban-mcp

The server identifies the agent through local process identity, so cards record which agent did what. Point your agent's MCP configuration at the kanban-mcp command. Ready-made configurations ship with the package.

Not only MCP

The same board is reachable through the web UI, a REST API and the kanban CLI, so agents without MCP support can still participate. Supported agents include Claude Code, Codex, OpenCode, Aider, Antigravity CLI, Cursor and Copilot; see integrations.

Scope

It is a single-operator, local tool: one shared token guards the local server, so do not expose it to an untrusted network. For how the pieces fit, read Local-first Kanban for coding agents.
